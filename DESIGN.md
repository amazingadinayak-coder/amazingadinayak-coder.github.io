# Personal Website Design Template

## 1. Brand Identity

### Color Palette

- **Primary Color**: #6366F1 (Indigo)
- **Secondary Color**: #EC4899 (Pink)
- **Background**: #0F172A (Dark Navy)
- **Text Color**: #E2E8F0 (Light Gray)
- **Accent/Highlight**: #10B981 (Emerald Green)

### Typography
- **Headings**: Source Code Pro - Bold (700)
- **Body Text**: IBM Plex Sans - Regular (400)
- **Code/Monospace**: IBM Plex Mono - Regular (400)

### Logo/Branding
 - Logo style: ASCII art representation of function() or method()
 - Favicon: Stylized function symbol
 - Theme: Developer-centric, playful


## 2. Layout Structure

### Header

- Navigation menu (Home, About, Projects, Experience, Contact)
- Logo/Name placement
- Mobile menu icon
- Theme toggle (optional)

### Hero Section

- Brief introduction/tagline
- Profile image/avatar
- Social media links

### Main Sections

#### About Me

- Professional summary
- Skills and expertise
- Technologies/Tools
- Downloadable resume/CV

#### Projects/Portfolio

- Project cards with:
  - Thumbnail image
  - Project title
  - Brief description
  - Technologies used
  - Links (live demo, GitHub)
- Filter/category options

#### Contact

- Contact form (name, email, message)
- Email address
- Social media links


### Footer

- Copyright notice
- Social media icons
- Quick links
- Back to top button

## 3. Design Elements

### Spacing

- Top Padding: 3rem (48px)
- Bottom Padding: 3rem (48px)
- Left Padding: 1.5rem (24px)
- Right Padding: 1.5rem (24px)
- Max-width: 1000px (62.5rem)
- Margin between elements: 1rem (16px)
- Margin between paragraphs: 1.5rem (24px)
- Margin between sections: 3rem (48px)

### Components

- **Buttons**: Style, hover effects, padding
- **Cards**: Border radius, shadow, hover effects
- **Forms**: Input styling, validation states
- **Images**: Border radius, aspect ratio, hover effects

### Animations/Transitions

- Page load animations
- Scroll effects
- Hover states
- Transition duration: 200 ms

## 4. Responsive Design

### Breakpoints

- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

### Mobile Considerations

- Hamburger menu
- Stack sections vertically
- Touch-friendly button sizes
- Optimized images
